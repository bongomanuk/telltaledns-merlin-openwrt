A release for routers: a daily blocklist refresh no longer takes the whole
device offline when memory runs short.

## Highlights

- **The shipped configs cap the memory used by a list compile.** A refresh
  builds a new snapshot while the old one keeps answering queries, and that
  peak was more than a 512 MB router had free. `[filter] compile_memory` is now
  `"16MiB"` in both the ASUS Merlin and OpenWrt starter configs, the lowest
  value the resolver accepts. Sorting spills to the snapshot directory early,
  so the refresh takes a little longer on a USB stick but stays inside the
  router's memory.
- **The list update no longer grows its memory with the size of the lists.** The
  sort used to hold up to 128 MiB before it spilled a run to disk. Its working
  batch is now capped at 1 MiB per parser thread, whatever `[filter] compile_memory`
  says, so the setting is a ceiling and cannot be used to exhaust a router. In
  measurements on this tree, a compile of the 86k-name light list went from 14 MiB
  peak RSS to 10 MiB, and a 1.5 M-name compile from 128 MiB to 48 MiB (most of
  which is the benchmark's own list text). The cost is more spill files and a
  slower refresh: about 0.37 s instead of 0.25 s for the light list.
- **An out-of-memory event kills the resolver, not the router.** The Merlin
  boot hook now marks TelltaleDNS with `oom_score_adj=500`. Asuswrt sets
  `vm.panic_on_oom=1`, which previously turned an OOM into a kernel panic and
  took down WAN, DNS and AiMesh together. With the resolver as the victim, only
  filtering stops: dnsmasq keeps port 53, answers local names and falls back to
  the plain upstreams in `dnsmasq.conf.add`. The resolver can then be restarted
  without rebooting the router.

## Upgrading

Most installs keep their existing config, so add the block yourself before you
add a larger list:

```toml
[filter]
compile_memory = "16MiB"
```

Re-run `install.sh` on Merlin to pick up the new boot hook (it replaces only
its own `# telltale` block). New installs get both changes already. If you have
a router with less than 512 MB, use a compact list and watch free memory during
a refresh before adding a bigger one.
